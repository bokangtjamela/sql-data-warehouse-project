# Data Warehouse and Analytics Project


## 📌 Project Overview


The project follows a practical Data Warehousing workflow covering **ETL/ELT processing, data integration, data cleansing, data loading, data architecture, and data modelling**.

The goal is not only to build the technical solution, but also to understand **why each stage is necessary and how the different components work together to support data-driven decision-making**.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Understand the fundamentals of Data Warehousing.
* Explore and prepare raw data from different sources.
* Design a suitable Data Warehouse architecture.
* Build staging and warehouse layers.
* Perform ETL processes using SQL.
* Clean and transform raw data.
* Integrate data from multiple sources.
* Design fact and dimension tables.
* Implement a dimensional data model.
* Load transformed data into the Data Warehouse.
* Validate data quality and consistency.
* Develop SQL queries for analytical purposes.
* Generate meaningful business insights from the warehouse.

## 📚 Key Concepts Covered

### ETL / ELT

Understanding the processes used to move data from source systems into a Data Warehouse.

**ETL:**

```text
Extract → Transform → Load
```

**ELT:**

```text
Extract → Load → Transform
```

### Data Architecture

Understanding how different components of a data system interact, including source systems, staging areas, Data Warehouses, and analytical layers.

### Data Integration

Combining data from multiple sources into a consistent and usable structure.

### Data Cleansing

Identifying and correcting issues such as:

* Missing values
* Duplicate records
* Incorrect data types
* Inconsistent formats
* Invalid values
* Inconsistent naming

### Data Modelling

Designing structured data models using concepts such as:

* Fact tables
* Dimension tables
* Primary keys
* Foreign keys
* Surrogate keys
* Star schemas
* Relationships
